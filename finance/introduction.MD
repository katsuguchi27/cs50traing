Українська:
Фінальний проект курсу CS50 від Harvard. ТЗ:Створення веб-додатку для покупки та продажу акцій з використанням API та бази даних. Від звичайного завдання відміність лише у реалізації механізму API, бо включений до завдання IEX (https://api.iextrading.com/) наразі не підтримується, був використаний Alpha Vantage(https://www.alphavantage.co/documentation/) з безкоштовним запитом 25 раз на день. Також як додаткове завдання було реалізовано механізм зміни пароля користувача. Решта умов завдання була реалізована без змін на базі фреймворку Flask на мові Python та sqlite3 бази данних .

English:
Final project for Harvard’s CS50 course. Requirements: Create a web application for buying and selling stocks using an API and a database. The only difference from the standard assignment is in the implementation of the API mechanism, since the IEX API (https://api.iextrading.com/) specified in the assignment is currently not supported; instead, Alpha Vantage (https://www.alphavantage.co/documentation/) was used, which allows 25 free requests per day. Additionally, a mechanism for changing the user’s password was implemented as an extra task. The rest of the task requirements were implemented as specified using the Flask framework in Python and the SQLite3 database.
